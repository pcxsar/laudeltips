⚙️ CONFIGURAÇÃO

Configure o Firebase para salvar as apostas na nuvem.

1. Crie o projeto Firebase
Acesse console.firebase.google.com → Adicionar projeto → dê um nome → Criar projeto
2. Ative o Firestore
Menu lateral: Criação → Firestore Database → Criar banco de dados → Modo de teste → southamerica-east1 → Ativar
3. Cole as credenciais no HTML
No arquivo index.html, localize o bloco firebaseConfig e substitua com os dados do seu projeto.
