⚙️ CONFIGURAÇÃO

Você precisa criar um projeto Firebase gratuito para salvar as apostas na nuvem. Siga os passos abaixo:

1. Crie o projeto Firebase
Acesse console.firebase.google.com → Adicionar projeto → dê um nome (ex: copa-bets) → desative o Google Analytics → Criar projeto
2. Ative o Firestore
No menu lateral: Criação → Firestore Database → Criar banco de dados → escolha Modo de teste (30 dias grátis, suficiente para a Copa) → selecione a região southamerica-east1 → Ativar
3. Registre o app Web
Na tela inicial do projeto → clique no ícone </> (Web) → dê um apelido → Registrar app → copie o bloco firebaseConfig = { ... }
4. Cole as credenciais no HTML
Abra o arquivo copa_bets.html em um editor de texto, encontre o bloco firebaseConfig e substitua cada campo COLE_SUA_... com os valores copiados. Depois faça push para o GitHub.
✅ Pronto!
Após o push, todas as apostas ficam salvas na nuvem. Qualquer amigo que abrir o link verá as mesmas apostas em tempo real. Alterações aparecem instantaneamente em todos os dispositivos.
